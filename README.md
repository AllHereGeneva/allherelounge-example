# All Here Lounge — example site

A showcase copy of three All Here Lounge pages, published with GitHub Pages:

- `index.html` — main page
- `attention-capital.html` — Attention Capital
- `booking/` — booking

The three pages link to each other; other menu items lead to the real allherelounge.com.

This copy is **disconnected from the live booking system**: it may read the public list of
sessions, but sign-in, booking, payments, gifts and analytics are all switched off. A small
"Example" label is shown on the page. Styles and images load from allherelounge.com.

The real page lives at https://allherelounge.com/booking/.
